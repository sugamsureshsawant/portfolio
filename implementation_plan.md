# Cybersecurity Portfolio Website

## Structure
- `index.html` — Main HTML file
- `style.css` — Styling with cybersecurity dark theme
- `script.js` — Animations, interactivity, certificate upload logic

## Sections
1. **Navigation** — Sticky nav with glitch logo
2. **Hero** — Terminal-style typing animation, particle background
3. **About** — Bio + animated stats
4. **Skills** — Animated skill bars (Penetration Testing, OSINT, etc.)
5. **Projects** — Card grid with hover effects
6. **Certifications** — Upload + display certificates (localStorage)
7. **Contact** — Form + social links

## Design
- Color palette: #0a0a0f (bg), #00ff41 (matrix green), #00d4ff (cyan), #ff006e (red accent)
- Font: JetBrains Mono + Inter
- Effects: Matrix rain, glitch text, neon glow, scanline overlay
